# store-django
- download the requirements in requirements.txt using : "pip install -r requirements.txt"
- there is no signup/login
- create admin/user with easy password using (in terminal): "python manage.py createsuperuser"
- to clear db (in terminal): "del db.sqlite3" then "python manage.py migrate"

## steps
- create user using "python manage.py createsuperuser"
- signin to http://127.0.0.1:8000/admin
- in 'bank' add balance to user (after creating any user its init 0) - may make it random number automaticly later
