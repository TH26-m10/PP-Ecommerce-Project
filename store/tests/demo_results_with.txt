======================================================================
  DEMO 1: User Create Failure
======================================================================
Simulating: Bank creation fails during user registration.

WITH transaction.atomic: User + Cart + Bank should ALL be rolled back.
WITHOUT transaction.atomic: User + Cart exist, but NO Bank (orphaned data!).


--- BEFORE ---
  Users:         300
  Carts:         0
  Banks:         0
  Orders:        0
  ProductOrders: 0
  Products:      300

>>> Exception raised: Bank creation failed!

--- AFTER ---
  Users:         300
  Carts:         0
  Banks:         0
  Orders:        0
  ProductOrders: 0
  Products:      300

>>> RESULTS:
    User exists:  False
    Cart exists:  False
    Bank exists:  False

    [OK]  All rolled back cleanly.

  DEMO 2: Checkout Payment Failure
======================================================================

            THEN payment gateway crashes.
